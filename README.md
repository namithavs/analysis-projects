# Analysis Projects – Namitha VS

This repository presents a portfolio of data analysis and dashboard projects, demonstrating practical experience in data visualization, reporting, and business insights using Power BI, Excel, Tableau, and PowerPoint.

---

## 1. Accounts Receivable (AR) Dashboard

**Objective:**  
Track outstanding payments and identify high-risk clients.

**Approach:**
- Collected and analyzed the dataset  
- Performed data cleaning using Power BI (Power Query)  
- Developed interactive dashboards for monitoring receivables  

**Key Insights:**
- Identified clients with delayed payments  
- Highlighted high-risk departments  

**Tools Used:** Power BI, Excel  

**Business Impact:**  
Improves visibility into receivables and supports efficient payment collection.
